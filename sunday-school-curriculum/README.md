# 📖 Through the Bible in 12 Months
### Purpose Church Sunday School Curriculum · Ages 4–17

A complete, ready-to-teach, 12-phase (12-month) Sunday school program that takes kids and teens through **all 66 books of the Bible, from Genesis to Revelation**, in the easiest words possible.

Every phase includes:

| | |
|---|---|
| 📖 **Bible in Easy Words** | Every book explained simply: what it's about, key people, key stories, and where Jesus shows up |
| 👩‍🏫 **Teaching Instructions** | Teacher background, a 4-week plan, ready-to-read story scripts, and tips for each age group |
| 📺 **YouTube Videos** | Weekly picks from **@SharefaithKids**, **@BibleJourneyTV** and **@bibleproject** |
| 🎵 **Book Memory Song** | A cumulative song with hand motions so kids memorize every book in order |
| 🔤 **Spelling & Reading** | Age-leveled spelling lists, syllable clapping, spelling bee words, and read-aloud practice |
| ❓ **Word Trivia** | 30+ questions per phase in Easy / Medium / Hard tiers, with answer keys |
| 🎮 **Games** | Active games that drill book names, spelling and stories |
| 🖍️ **Coloring** | Coloring page designs plus **printable** coloring sheets, tracing, word searches and flashcards |
| ✂️ **Activities & Crafts** | Hands-on projects for each phase |
| 💬 **Questions for Every Age** | Discussion questions for each age group, plus "Big Questions" for teens |
| 🏅 **Review & Celebration** | Check-offs, Bible Passport stamps, badges and certificates |
| 🏠 **Take-Home Family Page** | Verse, song, dinner-table questions and videos for home |

## 🚀 Start Here

1. Read the **[Program Overview](00-start-here/program-overview.md)** (vision, age groups, schedule, staffing).
2. Train volunteers with the **[Teacher Training Guide](00-start-here/teacher-training-guide.md)** (how to teach each phase, run games, trivia and spelling).
3. Learn the **[Books of the Bible Memory System](00-start-here/books-of-the-bible-memory-system.md)** (all 66 books with pronunciation, syllables, spelling and memory tricks).
4. Set up your video playlists with the **[YouTube Video Guide](00-start-here/youtube-video-guide.md)**.
5. Gather supplies with the **[Supply List](00-start-here/supply-list.md)**, and send home the **[Parent Welcome Letter](00-start-here/parent-welcome-letter.md)**.
6. Each Sunday, plan with the **[Weekly Session Template](00-start-here/weekly-session-template.md)** and the month's phase guide.
7. Keep the **[Game Library](00-start-here/game-library.md)** handy (33 reusable games).

## 👧🧒👦 Age Groups

| Group | Ages | Focus |
|---|---|---|
| 🐑 **Little Lambs** | 4–6 | Pictures, songs, hand motions, coloring, first letters |
| 🧭 **Explorers** | 7–10 | Stories, trivia, reading and spelling the book names |
| 🥾 **Trailblazers** | 11–13 | Maps, timelines, looking up verses, "why" questions |
| 🕊️ **Ambassadors** | 14–17 | Big themes, apologetics, real-life application, leading younger kids |

## 🖨️ Printables

Open **[printables/index.html](printables/index.html)** in a web browser and print. Each phase has a book-name coloring page, a picture coloring page, a Little Lambs tracing sheet, a spelling practice sheet, a word search with answer key, a word scramble with answer key, and cut-out flashcards color-coded by Bible section. Also included: a **[Bible Passport](printables/bible-passport.html)** and a **[Graduation Certificate](printables/certificate.html)**.

To change words or verses, edit `printables/build_printables.py` and run:

```bash
python3 sunday-school-curriculum/printables/build_printables.py
```
